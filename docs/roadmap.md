# Roadmap do projeto

## Versão 1
- Upload de CSV ou Excel
- Auditoria de campos vazios
- Auditoria de duplicidades
- Verificação de valores negativos e zerados
- Identificação de possíveis outliers
- Score de qualidade
- Diagnóstico executivo
- Gráfico automático simples
- Deploy em Streamlit

## Versão 2
- Exportar relatório de auditoria em Excel
- Permitir seleção de colunas obrigatórias pelo usuário
- Criar regras customizadas por tipo de relatório
- Melhorar gráficos automáticos
- Criar download da base tratada

## Versão 3
- Comparar duas versões de relatório
- Criar histórico de auditorias
- Integrar com SharePoint
- Integrar com Power BI
- Gerar diagnóstico com IA via API
